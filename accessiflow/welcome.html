Welcome to AccessiFlow

Your WCAG 2.2 accessibility companion for the web

What AccessiFlow Does

  • Automatically repairs accessibility issues for screen readers
  • Adjusts vision settings: contrast, dark mode, dyslexia-friendly fonts
  • Motor accessibility: large cursors, big click targets, stop animations
  • Cognitive aids: reading masks, line rulers, page simplification
  • Hearing support: image captions, video muting, closed captions
  • Built-in WCAG 2.2 audit: instant score & issue detection
  • AI-powered features via Claude API (optional)

Getting Started

Click the AccessiFlow icon in your browser toolbar to open the panel. Use the tabs to access different accessibility categories. Quick profiles let you apply presets in one click.

Settings are saved per-website automatically.

Keyboard Shortcuts

Alt+Shift+A Toggle AccessiFlow on/off Alt+Shift+H Heading navigation panel Alt+Shift+L Landmark navigation panel Alt+Shift+R Read page aloud (TTS) Alt+Shift+S Stop reading Alt+Shift+C Toggle high contrast Alt+Shift+F Toggle focus ring Alt+Shift+T Toggle large cursor Alt+Shift+M Toggle reading mask
